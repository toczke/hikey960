# 01. Building Modern Armbian for HiKey960

To escape the 4.19 kernel, we use the Armbian build framework to compile a modern "Edge" kernel (mainline Linux). 

## Prerequisites
You need a dedicated build machine (Ubuntu 22.04/24.04 recommended) with Docker installed, or you can run the build script natively. You need at least 30GB of free space.

## Build Process

1.  **Clone the Armbian Build Framework:**
    ```bash
    git clone https://github.com/armbian/build
    cd build
    ```

2.  **Start the Compilation:**
    Run the build script. We will specify the `hikey960` board and target the `edge` kernel branch.
    ```bash
    ./compile.sh \
        BOARD=hikey960 \
        BRANCH=edge \
        RELEASE=bookworm \
        BUILD_MINIMAL=no \
        BUILD_DESKTOP=no \
        KERNEL_ONLY=no \
        KERNEL_CONFIGURE=no
    ```
    *Note: You can change `RELEASE` to `jammy` or `noble` if you prefer Ubuntu over Debian.*

3.  **Output**
    Once the compilation finishes, your new OS image will be located in the `output/images/` directory. It will be a `.img` file (e.g., `Armbian_24.x.x_Hikey960_bookworm_edge_6.x.y.img`).

## Why not just flash this image directly?
Armbian's default build process generates a highly optimized partition table (often referred to as `maxroot`), which removes unused Android partitions like `cache` to maximize rootfs space. 

**DO NOT flash the `ptable` generated by Armbian.** If you do, you will break the HiKey960's EDK2 UEFI auto-boot mechanism. Proceed to Document 02 for the correct flashing methodology.
